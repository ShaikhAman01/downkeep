Downkeep
Careful cleanup for your Downloads folder.


TO OPEN IT

1. Right-click the downloaded zip and choose "Extract All".
   Opening it from inside the zip does not work.
2. Move the Downkeep folder somewhere it can stay, such as Documents.
   Keep the folder together. Downkeep.exe needs the _internal folder next to it.
3. Open the folder and double-click Downkeep.

It opens in its own window, using a browser you already have.


THE WARNING YOU WILL SEE

The first time, Windows will probably say "Windows protected your PC" and
"Unknown publisher". That is because Downkeep is free and not signed with a
paid certificate, so Windows cannot tell who made it. Windows shows this for any
new program like that. It does not mean something was found, and it does not
prove the program is safe either.

If you got it from github.com/ShaikhAman01/downkeep and want to go on:
   choose "More info", then "Run anyway".

You can check the download first. The release page lists a SHA-256 for the zip.
Right-click in the folder with the zip, choose "Open in Terminal", and type
   Get-FileHash Downkeep-*.zip
The two must be the same.

On some computers Smart App Control blocks unsigned programs completely and
there is no "Run anyway". Please do not turn it off for this.

If your antivirus says it found something, do not go on. Please tell us at
github.com/ShaikhAman01/downkeep/issues


WHAT IT DOES

- Shows what is in your Downloads folder and what takes space.
- Finds exact copies, and zips whose every file is already unpacked. Nothing
  else is called clutter. You choose what goes to the Recycle Bin.
- Tidies loose files into folders. You see the plan first, and can undo it.
- If you turn Automatic on, it tidies new files every hour. It starts off.
  Automatic never uses the Recycle Bin.


WHAT IT NEVER DOES

- It never deletes a file for good.
- It never replaces a file with another one.
- It never sends anything anywhere. The window is served from your own
  computer and only answers to itself.
- It never asks for an administrator password.


TO REMOVE IT

1. If you turned Automatic on, open Downkeep and turn Automatic off.
   (Already deleted the folder? Open Task Scheduler and delete the task named
   Downkeep.)
2. Close Downkeep and delete the Downkeep folder.
3. To remove its history too, delete %LOCALAPPDATA%\Downkeep
   (paste that into the address bar of a folder window).

Files that were tidied stay where they are.
